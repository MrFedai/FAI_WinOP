# FAI_WinOP

[![CI](https://github.com/MrFedai/FAI_WinOP/actions/workflows/ci.yml/badge.svg?branch=dev)](https://github.com/MrFedai/FAI_WinOP/actions/workflows/ci.yml)

Profile-based optimizer for Windows 11. One command after a fresh install applies your settings, apps and desktop layout.
Every change is snapshotted and can be undone.

## Quick start

Open PowerShell **as administrator**.

Preview (changes nothing):

```powershell
& ([scriptblock]::Create((irm https://github.com/MrFedai/FAI_WinOP/releases/latest/download/get.ps1))) -Profile fedai -DryRun
```

Run:

```powershell
& ([scriptblock]::Create((irm https://github.com/MrFedai/FAI_WinOP/releases/latest/download/get.ps1))) -Profile fedai
```

Undo the last run:

```powershell
& ([scriptblock]::Create((irm https://github.com/MrFedai/FAI_WinOP/releases/latest/download/get.ps1))) -Undo
```

Without `-Profile` an interactive menu opens.

## What the `fedai` profile does

<!-- profile:fedai:begin -->
<!-- Generated by build/ProfileDoc.ps1 from profiles/fedai.json, tweaks/ and apps/catalog.json. Do not edit by hand. -->

1. **Checks:** admin rights (UAC), session owner, safe data folder, log file.
2. **First:** System Restore point.
3. **Apps (12):** Claude, Telegram Desktop, WhatsApp, Discord, Steam, TradingView, Ollama, Visual Studio Code, Proton VPN, Google Chrome, Spotify, OBS Studio.
4. **Tweaks (27):**
   - **setup:** Turn off background apps · Microsoft Store: automatic updates, video and personalization off · Default browser · Windows Update: install pending first, then pause
   - **graphics:** NVIDIA: tray icon and legacy sharpening off (HasNvidia) · AMD: simplified Adrenalin and low latency (HasAmdGpu) · NVIDIA: stay in the P0 power state (HasNvidia)
   - **ui:** Black theme · Lock and sign-in screen black · Default account pictures black · Taskbar: buttons off, tray in overflow, only File Explorer + Chrome · Turn off Widgets · Turn off Copilot · Notepad settings · File Explorer layout · Reduce visual effects · Turn off notifications
   - **bloat:** Remove unnecessary Store apps · Keep removed apps from coming back · Remove Microsoft Edge
   - **sound:** Turn off the startup sound · Set the volume level
   - **privacy:** Minimize telemetry · Turn off app permissions · Turn off search and Start ads
   - **power:** Power plan: high performance on AC, balanced on battery
   - **system:** Timer resolution 0.5 ms
5. **Layout:** taskbar center, auto-hide, pins: Explorer + Google Chrome; desktop icons: recycleBin, thisPC; Start layout.
6. **Finish:** shell refresh and a summary. No automatic restart; if Windows updates need one, the run resumes after it.

Every change is snapshotted first; `-Undo` reverts the last run. Not reverted: the restore point, installed Windows updates, the default browser (set by hand), keep removed apps from coming back.

## Safety

- The download is checked against the release's SHA-256 file and run from a folder only administrators can write to.
- SHA-256 catches corruption, not a forged release (signing is planned).
- `Caution` tweaks ask `Y` / `N`, `Risk` tweaks ask you to type `YES`; `Risk` never runs with `-Unattended`.
- If you elevate with a different admin account, it stops (exit code 3); `-AllowOtherUser` overrides.

## Options

`-DryRun` · `-Undo [-Session <id>] [-SkipFailed]` · `-Unattended` · `-Only` / `-Skip` · `-UpdatesOn` / `-UpdatesOff` ·
`-ExportProfile <name>` · `-ExportLayout` · `-Version vX.Y.Z` · `-List` · `-AllowOtherUser`.
Profiles are plain JSON (`profiles/`), loaded from a path or URL, with no personal data.
